## 📌 About

**RoktoLagbe?** is a full-stack web platform built to connect blood donors with patients who urgently need blood. The platform focuses on **efficiency**, **accessibility**, and **real-time response** — making blood donation more organized during emergencies.

The purpose is simple but powerful: technology that can directly contribute to saving lives.

---

## ✨ Features

- 🔴 **Real-time donor-patient matching** — find the right blood type fast
- 🏥 **Hospital dashboard** — hospitals manage blood stock and requests
- 👤 **Donor profiles** — manage blood type, donation history, availability
- 🔔 **Push notifications** — alert nearby donors when blood is urgently needed
- 💬 **In-app chat** — communicate between donor and patient
- 🌐 **Multi-language support** — Bengali and English
- 🛡️ **Admin panel** — manage users and platform activity
- ♿ **Accessibility-first design** — built to be usable by everyone

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/RashaOsman2/rokto-lagbeWebApp.git

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Fill in your Firebase and Supabase credentials

# 4. Run development server
npm run dev
```

---

## ⚙️ Environment Variables

See `.env.example` for all required variables. You'll need:
- Firebase project credentials (Auth, Firestore, Storage, FCM)
- Supabase project credentials (URL + anon key)
